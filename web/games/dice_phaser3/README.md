# Dice Noir City - Pure React JS Web RPG

TypeScript 타입 검사 과정 없이 Cloudflare Pages에서 100% 한 번에 빌드되는 **순수 JavaScript (React JSX)** 버전입니다.

## 배포 설정 안내 (Cloudflare Pages)

Cloudflare Pages 대시보드에서 빌드 설정을 아래와 같이 입력해 주시면 됩니다.

- **Build command**: `npm run build` (또는 `npx vite build`)
- **Build output directory**: `dist`
