# HAHAO GAMES — Static Prototype

This folder contains a static prototype of the HAHAO GAMES landing page (placeholder assets).

To preview locally, open `web/index.html` in a browser or serve with a simple static server.

Quick preview with Python (from repository root):

```bash
python -m http.server 8000 --directory web
# then open http://localhost:8000
```

Replace placeholder images in `web/` with production assets (logo, thumbnails, hero background) to refine the design.
